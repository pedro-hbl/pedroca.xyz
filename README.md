# Pedro Lopes — Tech Blog

Personal blog about software engineering: JVM internals, Kotlin, AWS, distributed systems, and functional programming.

**Live site:** https://pedro-hbl.github.io/

## How it works

- Static site generated with [Marmite](https://github.com/rochacbruno/marmite), styled with a custom Windows 95 retro theme.
- The repository contains the generated output; it is served directly by [GitHub Pages](https://pages.github.com/) from the `main` branch (no build step — `.nojekyll` disables Jekyll processing).

## Publishing changes

Commit to `main` and push. GitHub Pages redeploys automatically within a minute or two.
